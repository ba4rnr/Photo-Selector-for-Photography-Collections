# 摄影集照片筛选器

Photo Selector —— 一个本地运行的桌面工具，服务于「拍摄 → 挑片 → 归档成片」里的挑片环节：
打开一个拍摄文件夹，快速过片，把要留的挑进目标文件夹，并自动重新编号。

## 简介

- 素材目录树支持双击浏览每个子文件夹；底部胶片条像 Lightroom 一样横向滚动、按子文件夹分组、可收起
- 挑中的照片进入目标文件夹的虚拟工作区（"中间商"），排序、编号、撤销都在内存里即时完成，不碰磁盘
- 按「保存」或关闭程序时改动才落到磁盘：复制新增照片、按新顺序重命名、重写带旋转/翻转的照片、永久删除被拖进垃圾桶的照片
- 运行期间持续监听目标文件夹，在外部手动增删改名，界面会立即跟上
- 界面配色取自 Capture One 的暗色主题；首版支持 JPG，DNG（读取内嵌全尺寸预览）随后接入

项目处于起步阶段：核心域模型已完成，界面骨架已就绪，功能逐块补齐。

## 常用命令

```bash
mvn clean package     # 编译、跑测试并打包

java -jar target/photo-selector.jar   # 运行
```

## 怎么跑起来

**双击项目根目录下的 `运行.cmd`**。它会先构建（第一次慢一点），然后用 `javaw` 启动窗口，
不留一个黑框在任务栏里。构建失败时窗口会停住并显示错误，方便把信息发回来。

也可以：在 IntelliJ 里直接运行 `PhotoSelectorApp`，或者手动执行
`mvnw.cmd package` 之后 `java -jar target\photo-selector.jar`。

## 打包 Windows 免安装版

使用 JDK 自带的 `jpackage` 生成带 Java 运行时的 Windows 应用，不要求目标电脑另装 Java：

```powershell
mvnw.cmd package
New-Item -ItemType Directory -Force target\jpackage-input | Out-Null
Copy-Item target\photo-selector.jar target\jpackage-input\photo-selector.jar -Force
jpackage --type app-image --dest dist --name "摄影集照片筛选器" `
  --app-version 0.1.0 --vendor BA4RNR `
  --input target\jpackage-input --main-jar photo-selector.jar `
  --main-class com.photoselector.PhotoSelectorApp
Compress-Archive -LiteralPath "dist\摄影集照片筛选器" `
  -DestinationPath "dist\PhotoSelector-0.1.0-windows-x64.zip" -Force
```

成品在 `dist\摄影集照片筛选器\`，双击其中的 EXE 即可运行；
`dist\PhotoSelector-0.1.0-windows-x64.zip` 可直接拷贝到另一台 Windows 电脑。

## 现在可以试什么

选择工作区之后，下面这些已经能用了：

- **文件 → 选择工作区…**（快捷键 Ctrl+O）：选素材根文件夹、在树上勾掉不想看的子文件夹、选目标文件夹。
  选过之后会记住，下次打开直接恢复，并回到上次关闭时正在浏览的照片，
  该照片会居中显示在底部缩略图条里；
  素材根文件夹要是找不到了，会提示你重选。
- **主窗口的位置、大小和最大化状态**也会记住；显示器拔掉或分辨率变小后，
  旧坐标已经落在屏幕外时会自动在当前屏幕居中，避免窗口打开后找不到。
- 素材条按组浏览：
  根目录下的**每个子文件夹是一组**，组头写着名字和张数；根目录自己散落的照片另算一组。
  分组只到根目录的直接子文件夹这一层：如果某个子文件夹自己也有照片、下面还有更深一层，
  素材条只显示它这一层的照片，不会把更深一层递归并进来。
- **素材文件会被实时跟进**：在资源管理器里给根目录或直接子文件夹增删、改名、覆盖 JPG 后，
  素材条和目录树会自动重扫；当前照片还在就保持选中，同名文件被覆盖时大图也会重读。
- **点组头**收起或展开那一组。收起后只留一条窄边，名字还看得见。
- **点左边目录树里的文件夹**，底部素材条滚到对应那一组。
- **取消目录树里某个文件夹前的小方框**，那一组就从素材条上消失——这就是设计里的"剔除"。
- **点中素材条里的一张照片，按空格键**，把它加进目标文件夹。右栏会立刻出现它，
  并在下面算出它将来在磁盘上的名字（`010`、`020`、`0230`……）。
- **点中素材条里的一张照片，中间就显示它的原图**（不是缩略图放大）；表头写着文件名、像素和所在文件夹。
- **左右方向键连续过片**：选中框在视口左半边时先自由右移；越过中线且右边还有内容时，
  素材条跟随滚动并把当前照片保持在视口中央；到末尾后停止滚动，选中框自然走到最后一张。
- **大图会预读取浏览顺序里的上一张和下一张**：连续过片通常可以直接上屏。
  内存中只保留当前张与这两张邻居；直接点到更远的照片时，旧缓存立即释放，未完成的旧预读取也会取消。
- **右栏就是"假如现在按保存，目标文件夹会是什么样"**：底色是目标文件夹里已有的照片，
  橙色名字的是这次新挑进去的。挪动顺序编号会跟着变，因为这些名字是按位置现算的。
- **Ctrl+Z 撤销**（挑入、挪位、丢进垃圾桶都算）。
- **保存（Ctrl+S，或工具栏上的"保存"）**：把改动一次性落到磁盘——复制新挑进来的、
  按新顺序给原有的文件改名、重写真正编辑过的照片、删掉垃圾桶里的真实文件。
  保存时会先写临时文件再原子落位，免得复制失败留下半截 JPG，也避免互换名字时互相覆盖。
- **查看 → 缩略图大小**：调右栏目标文件夹里缩略图的尺寸（小 / 中 / 大）。
  拖分隔条改变的是**间距**，照片本身不跟着缩放。
- **拖三条分隔线**（左栏右边、中间右边、底栏上方）调整布局，鼠标压到线上会亮出细白边。
  放大窗口或重新最大化时，底栏保持原高度，新增空间留给大图。
- **点工具栏最右边的"整理模式"**，中间和右侧会切换成整理布局。

- **缩放**：表头右侧有「适应」「100%」，鼠标滚轮也能缩放（5%~800%）。
  放大超过 100% 时改用最近邻插值——看得清真正的像素，而不是被插值糊成一片。
  新照片默认适应窗口；可在「查看 → 默认缩放」里切换 Fit 或固定百分比，选择会记住。
- **平移**：图比窗口大时按住左键拖动。拖到图片边缘与窗口边缘对齐就停住，
  拖不出视野；换回适应窗口会回到中间。
- **裁切**：点工具栏「裁切」或「图像 → 裁切」后，完整画面四角和四边会出现白色裁切条；
  可拖动裁切条或直接在画面内部拖出新框，选框外会压暗。裁切完成后仍停留裁切模式，
  直到手动点「选择」或「平移」；裁切可以和旋转、翻转叠加，保存时写进 JPG。
- **网格**：工具栏「网格」切换三分辅助线，只影响查看，不写入文件或编辑历史。
- **整理模式底栏**：横向显示目标文件夹照片和保存后编号；点击会同步选中并定位中间大网格，
  可直接拖动排序（白线标出落点），获得焦点后左右键也能连续选片。
- **编排模式表头的缩略图尺寸控制**：右侧「收起」左边有 `− 当前尺寸 +`，可按档快速放大 / 缩小网格缩略图。

还没做的部分：编号规则的配置界面，以及 DNG 浏览和 DNG → 全尺寸 JPG 导出。
当前版本只把 JPG / JPEG 当作照片；DNG 可以在目录树里作为普通文件看到，但不会进入素材条、大图或保存流程。

## 开发约定

- 源码统一使用 UTF-8 编码。
- 主代码放在 `src/main/java`，测试放在 `src/test/java`，两者包结构保持一致。
- 本地的照片素材放在 `photos/`、`samples/` 下，已在 `.gitignore` 中排除，不会误传进仓库。
