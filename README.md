# 摄影集照片筛选器

Photo Selector —— 一个本地运行的桌面工具，服务于「拍摄 → 挑片 → 归档成片」里的挑片环节：
打开一个拍摄文件夹，快速过片，把要留的挑进目标文件夹，并自动重新编号。

## 简介

- 素材目录树支持双击浏览每个子文件夹；底部胶片条像 Lightroom 一样横向滚动、按子文件夹分组、可收起
- 挑中的照片进入目标文件夹的虚拟工作区（"中间商"），排序、编号、撤销都在内存里即时完成，不碰磁盘
- 按「保存」或关闭程序时改动才落到磁盘：复制新增照片、按新顺序重命名、永久删除被拖进垃圾桶的照片
- 运行期间持续监听目标文件夹，在外部手动增删改名，界面会立即跟上
- 界面配色取自 Capture One 的暗色主题；首版支持 JPG，DNG（读取内嵌全尺寸预览）随后接入

项目处于起步阶段：核心域模型已完成，界面骨架已就绪，功能逐块补齐。

## 常用命令

```bash
mvn clean package     # 编译、跑测试并打包
mvn test              # 只跑测试
mvn clean compile     # 只编译
java -jar target/photo-selector.jar   # 运行
```

## 怎么跑起来

**双击项目根目录下的 `运行.cmd`**。它会先构建（第一次慢一点），然后用 `javaw` 启动窗口，
不留一个黑框在任务栏里。构建失败时窗口会停住并显示错误，方便把信息发回来。

也可以：在 IntelliJ 里直接运行 `PhotoSelectorApp`，或者手动执行
`mvnw.cmd package` 之后 `java -jar target\photo-selector.jar`。

## 现在可以试什么

打开素材文件夹之后，下面这些已经能用了：

- **文件 → 打开素材文件夹…**（快捷键 Ctrl+O），挑一个里面装着 JPG 的文件夹。
  根目录下的**每个子文件夹是一组**，组头写着名字和张数；根目录自己散落的照片另算一组。
- **点组头**收起或展开那一组。收起后只留一条窄边，名字还看得见。
- **点左边目录树里的文件夹**，底部素材条滚到对应那一组。
- **取消目录树里某个文件夹前的小方框**，那一组就从素材条上消失——这就是设计里的"剔除"。
- **拖三条分隔线**（左栏右边、中间右边、底栏上方）调整布局，鼠标压到线上会亮出细白边。
- **点工具栏最右边的"整理模式"**，中间和右侧会切换成整理布局。

还没做的部分：中间的大图还不会显示照片、目标文件夹与垃圾桶是空的、
保存与导出、以及记住上次打开的工作区。

## 开发约定

- 源码统一使用 UTF-8 编码。
- 主代码放在 `src/main/java`，测试放在 `src/test/java`，两者包结构保持一致。
- 本地的照片素材放在 `photos/`、`samples/` 下，已在 `.gitignore` 中排除，不会误传进仓库。
